# AI & Machine Learning Bootcamp

## معسكر الذكاء الاصطناعي وتعلّم الآلة

معسكر الذكاء الاصطناعي وتعلّم الآلة — مسار مكثّف من أساسيات ML إلى NLP والذكاء التوليدي (GenAI) وMLOps.


| البند     | التفاصيل                                              |
| --------- | ----------------------------------------------------- |
| **المدة** | **5 أيام** — يومياً ~8 ساعات (40 ساعة تدريبية مكثّفة) |


---

## فكرة المعسكر

معسكر **تطبيقي مكثّف لمدة 5 أيام** يأخذ المتدرب من «كيف أبني pipeline تعلّم آلي صحيح» إلى «كيف أستخدم نماذج لغوية وتوليدية في منتج حقيقي».

الفكرة ليست حفظ خوارزميات منفصلة، بل:

1. **فهم المسار الكامل:** بيانات خام → معالجة → نموذج → تقييم → نشر.
2. **ربط النظري بالعملي:** كل يوم يقترن بشرائح عرض وتمارين تطبيقية.
3. **مسار واحد متسق:** من الانحدار والتصنيف الكلاسيكي → التعلم العميق → NLP → GenAI وRAG.

## مخرجات المعسكر

بنهاية **الأيام الخمسة**، يُتوقَّع أن يكون المتدرب قادراً على:

- بناء **pipeline ML كامل**: تقسيم بيانات، تحجيم، ترميز، تدريب، تقييم
- اختيار نموذج مناسب (انحدار، تصنيف، تجميع، شبكة عصبية) حسب البيانات والقيود
- تفسير **مقاييس التقييم** (R²، confusion matrix، precision/recall، perplexity، BLEU)
- تنفيذ **معالجة نص** عملية: تنظيف، tokenization، POS، NER
- شرح مفاهيم **GenAI** (encoder/decoder، attention، BERT vs GPT)
- وصف بنية **RAG** ومتى تُستخدم في المنتجات
- فهم أساسيات **MLOps**: إصدارات، مراقبة، CI/CD للنماذج
